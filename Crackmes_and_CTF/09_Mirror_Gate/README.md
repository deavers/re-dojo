# CM 09 — The Mirror Gate (Tier E-- · 0.9)

**Предпосылки:** CM 01 (строки в `.rdata` и строки, собранные на стеке).
**Новая идея:** пароль хранится не текстом, а после простой обратимой трансформации. Нужно найти цикл
сравнения, понять, что он делает с вводом, и обратить это — вручную или парой строк Python.

## Цель

Ввести пароль, который открывает Зеркальные врата. Программа печатает `FLAG{<пароль>}`.

| Код выхода | Значение |
| :-: | :--- |
| 0 | врата открыты, флаг напечатан |
| 1 | неверный пароль |
| 2 | неверная длина |
| 3 | конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target crackme09_mirror
.\build\bin\Release\crackme09_mirror.exe
```

## Как проверяется

* В репо — только sha256 флага (`check/expected.json`); пароля в исходнике нет, только закодированные байты.
* Автопроверка (CTest): `cm09_build`, `cm09_solve_ok`, `cm09_wrong_fails`. Неверные ответы, которые обязаны
  провалиться: сдвиг снят, а зеркало нет; закодированные байты как есть; сдвиг в обратную сторону; неверный
  регистр; на одну букву короче (код 2).
* `solve/solve.py` — спойлер.
