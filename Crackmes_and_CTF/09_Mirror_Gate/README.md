# CM 09 — The Mirror Gate (Tier E-- · 0.9)

**Предпосылки:** CM 01 (строки в бинаре).

## Цель

Ввести пароль, который открывает Зеркальные врата. Программа печатает `FLAG{<пароль>}`.

## Формат ввода

Одна строка — пароль.

| Код выхода | Значение |
| :-: | :--- |
| 0 | принят, флаг напечатан |
| 1 | отклонён |
| 2 | неверный формат / длина |
| 3 | конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target crackme09_mirror
.\build\bin\Release\crackme09_mirror.exe
```

## Как проверяется

* Флаг — сам пароль (`FLAG{<пароль>}`); в репо — только его sha256 (`check/expected.json`), в исходнике пароля нет.
* Автопроверка (CTest): `cm09_build`, `cm09_solve_ok`, `cm09_wrong_fails` — эталонный ответ проходит, все неверные ответы из `solve/solve.py` (включая обходные) проваливаются.
* Подсказки — на карте (`docs/dojo-map.html`), `solve/solve.py` — спойлер.
