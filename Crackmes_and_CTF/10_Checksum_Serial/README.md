# CM 10 — The Checksum Serial (Tier D- · 2.6)

**Предпосылки:** CM 02 (арифметика серийника, первый кейген на Python).
**Новая идея:** серийник принимается по **правилам**, а не сравнением с одним сохранённым значением: контрольная
цифра (алгоритм Луна), правило суммы цифр и блок, вычисленный из другого блока. Верных серийников много —
восстанови все три правила и напиши кейген, который выдаёт любой из них.

## Цель

Ввести серийник формата `NNNN-NNNN-NNNN-NNNN`, который проходит все проверки. Программа печатает флаг; он не
зависит от того, какой именно верный серийник введён.

| Код выхода | Значение |
| :-: | :--- |
| 0 | принят, флаг напечатан |
| 1 | нарушено одно из правил |
| 2 | неверный формат |
| 3 | конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target crackme10_checksum_serial
.\build\bin\Release\crackme10_checksum_serial.exe
```

## Как проверяется

* В репо — только sha256 флага (`check/expected.json`).
* Автопроверка (CTest): `cm10_build`, `cm10_solve_ok`, `cm10_wrong_fails`. Эталонный кейген (`solve/solve.py`)
  генерирует серийник; каждый неверный пример ломает ровно одно правило (остальные пересчитаны): контрольная
  цифра, сумма цифр, производный блок; плюс два примера неверного формата (код 2).
* `solve/solve.py` — спойлер.
