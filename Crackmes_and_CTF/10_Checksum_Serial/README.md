# CM 10 — The Checksum Serial (Tier D- · 2.6)

**Предпосылки:** CM 02 (арифметика серийника, первый кейген на Python).

## Цель

Ввести серийник, который программа принимает. При каждом запуске программа печатает новый случайный блок
(`CHALLENGE: BBBB`), и серийник обязан его содержать — значит, нужен кейген, а не один найденный серийник.

## Формат ввода

`DOJO-AAAA-BBBB-CCCC-D` — префикс `DOJO-`, три блока по 4 цифры и одна цифра; `BBBB` — блок из `CHALLENGE`.

| Код выхода | Значение |
| :-: | :--- |
| 0 | принят, флаг напечатан (в нём подмешан серийник) |
| 1 | нарушено одно из правил |
| 2 | неверный формат |
| 3 | конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target crackme10_checksum_serial
.\build\bin\Release\crackme10_checksum_serial.exe
```

## Как проверяется

* Флаг зависит от серийника, поэтому в репо его хэша нет: раннер читает `CHALLENGE`, эталонный кейген
  (`solve/solve.py`) отвечает, а ожидаемый флаг считается независимо на Python (`expected_flag`).
* Автопроверка (CTest): `cm10_build`, `cm10_solve_ok` (3 запуска с разными вызовами), `cm10_wrong_fails`.
* Подсказки — на карте, `solve/solve.py` — спойлер.
