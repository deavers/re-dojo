# CM 17 — The Register Machine (Tier S- · 7.4)

**Предпосылки:** CM 06 (стековая VM, свой дизассемблер).

## Цель

Ввести 8-символьный ключ, который принимает машина. Программа печатает `FLAG{<ключ>}`.

## Формат ввода

Одна строка — ключ из 8 символов.

| Код выхода | Значение |
| :-: | :--- |
| 0 | принят, флаг напечатан |
| 1 | отклонён |
| 2 | неверный формат / длина |
| 3 | конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target crackme17_register_vm
.\build\bin\Release\crackme17_register_vm.exe
```

## Как проверяется

* Флаг — сам ключ (`FLAG{<ключ>}`); в репо — только его sha256 (`check/expected.json`), в исходнике ключа нет.
* Автопроверка (CTest): `cm17_build`, `cm17_solve_ok`, `cm17_wrong_fails` — эталонный ответ проходит, все неверные ответы из `solve/solve.py` (включая обходные) проваливаются.
* Подсказки — на карте (`docs/dojo-map.html`), `solve/solve.py` — спойлер.
