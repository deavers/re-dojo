📖 Reverse Engineering, x86/x64 Calling Conventions & Engine Cheat Sheet

Quick reference for ABI registers, opcode byte patches, Cheat Engine Auto Assembler templates, and game engine memory landmarks.

1. x86 & x64 Calling Conventions (Where Function Arguments Live)

ABI / Convention Architecture Integer / Pointer Args Float / Vector Args Return Value Stack Cleanup & Notes
__cdecl x86 (32-bit) Stack [esp+4], [esp+8]... Stack EAX / ST(0) Caller cleans stack (add esp, X). Standard C default.
__stdcall x86 (32-bit) Stack [esp+4], [esp+8]... Stack EAX Callee cleans stack (ret 0x0C). Standard Win32 API.
__thiscall x86 (32-bit MSVC) ECX = this ptr; rest on Stack Stack EAX Callee cleans stack. Default for 32-bit C++ class member functions!
Microsoft x64 ABI x64 (Windows) RCX, RDX, R8, R9 (RCX = this) XMM0, XMM1, XMM2, XMM3 RAX / XMM0 Caller reserves 32-byte Shadow Space on stack before call.
System V AMD64 ABI x64 (Linux / PS4 / macOS) RDI, RSI, RDX, RCX, R8, R9 (RDI = this) XMM0 – XMM7 RAX / XMM0 128-byte Red Zone below RSP; no shadow space required.

2. Essential Opcode Byte Patches (Hex Patching Quick Reference)

Patch Goal Assembly Instruction Hex Bytes Typical Use Case
No Operation (NOP) nop / 2-byte 66 90 90 Erase ammo/stamina subtraction or unwanted function call
Unconditional Short Jump jmp short +offset EB <rel8> Replace conditional branch 74 (je) or 75 (jne) with EB (always jump)
Unconditional Near Jump jmp near +offset E9 <rel32> 5-byte relative detour used by Cheat Engine codecaves & MinHook
Invert Conditional Near Jump je ↔ jne 0F 84 ↔ 0F 85 Flip license check or damage check condition (6-byte instruction)
Force Function Return False (0) xor eax, eax; ret 31 C0 C3 Instantly return 0 / false at function prologue (e.g. IsDebuggerPresent / destroyPlayer)
Force Function Return True (1) mov al, 1; ret B0 01 C3 Instantly return 1 / true at validation function prologue (e.g. HasDLC / CheckKey)
64-Bit Absolute 14-Byte Jump jmp qword ptr [rip+0]; dq addr FF 25 00 00 00 00 <8-byte addr> Full 64-bit trampoline jump when target codecave is >2 GB away
