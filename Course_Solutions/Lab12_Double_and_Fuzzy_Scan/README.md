# Lab 12 — Double & Fuzzy Scans (Tier F+ · 0.6)

**Предпосылки:** Lab 02 (float, int16, битовая маска).
**Новая идея:** на экране — округлённые числа, поэтому точный скан по видимому значению не находит ничего.
Поиск через «Unknown initial value» + «Increased / Decreased value» и разница между `double` (8 байт)
и `float` (4 байта).

## Цель

Философский камень образуется, когда одновременно:

| Требование | Тип в памяти |
| :--- | :--- |
| Эссенция не меньше 1 000 000 | `double`, на экране округлена до десятых |
| Чистота катализатора не меньше 99,9 % | `float`, на экране — округлённые проценты; фильтр в игре упирается в 95 % |

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab12_double_fuzzy
.\build\bin\Release\lab12_double_fuzzy.exe
```

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab12_build`, `lab12_solve_ok`, `lab12_wrong_fails`. Неверные ответы, которые
  обязаны провалиться: эссенция записана как float, чистота как double, чистота как целое 1, эссенция чуть
  ниже цели, запись за границу структуры.
* `solve/solve.py` — спойлер.

## Где пригодится на карте

Игры, где деньги и ресурсы хранятся в `double`, а множители — во `float`, и экран их округляет
(кликеры, idle-игры, экономические симуляторы).
