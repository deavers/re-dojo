# Lab 52 — Embedded Lua 5.4: lua_State (Tier A · 6.3 · только Windows для практики)

**Предпосылки:** Lab 09 (внутренняя DLL, вызов функций), Lab 17 (раскладка структур).
**Новая идея:** логика многих игр крутится во встроенной Lua VM. Вместо охоты за числами найди `lua_State`
игры и выполни в нём свой Lua-код: из внедрённой DLL возьми `luaL_loadstring` / `lua_pcallk` из `lua54.dll`
(`GetProcAddress`), прочитай указатель на состояние из объекта движка и выполни кусок кода.

Lua — `third_party/lua` (Lua 5.4.9, MIT, без изменений), собирается как `lua54.dll`. Окружение игры урезано:
только base / table / string / math, без `io`, `os`, `package`, `dofile`, `loadfile`.

## Цель

Гильдия архимагов принимает героя с `hero.gold >= 1000000` и `hero.title == "Archmage"`. Скрипт добавляет только
1 золото за ход и никогда не меняет титул — измени их через собственный `lua_State` игры.

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab52_embedded_lua
.\build\bin\Release\lab52_embedded_lua.exe     # lua54.dll лежит рядом
```

Практика: своя DLL по образцу `Tools_and_Scripts/03_Internal_DLL_Skeleton`, которая берёт функции из
`lua54.dll`, читает `lua_State*` из движка и выполняет код. Работает только на Windows (подпись «только Windows»
на карте); сама лаба и автопроверка собираются и на Linux.

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest, метка `windows`; в CI — задача `windows-labs`): `lab52_build`, `lab52_solve_ok`,
  `lab52_wrong_fails`. Selftest моделирует внедрённую DLL: `luado <смещение> <код>` читает указатель из `g_Engine`,
  **сверяет его с настоящим `lua_State`** (неверное смещение отклоняется, ничего не разыменовывается) и выполняет
  код через `luaL_dostring`. Неверные ответы: не то смещение, мало золота, новые глобальные переменные вместо полей
  `hero`, золото строкой, `os.exit` (в песочнице нет `os` — ошибка Lua, а не выход), синтаксическая ошибка.
* `solve/solve.py` — спойлер.

## Где пригодится на карте

Игры со встроенной Lua / LuaJIT: логика, предметы и баланс задаются скриптами, и правка через `lua_State`
надёжнее поиска чисел.
