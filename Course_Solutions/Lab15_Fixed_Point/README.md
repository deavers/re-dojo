# Lab 15 — Fixed-Point 16.16 (Tier E- · 1.1)

**Предпосылки:** Lab 12 (неточный скан, `double` и `float`).
**Новая идея:** дробное число — не обязательно float. В старых движках, физике и эмуляторах консолей
дробь часто хранится в фиксированной точке: обычный 4-байтовый int, у которого младшие 16 бит — дробная
часть (значение = raw / 65536). Скан Float ничего не найдёт — нужно искать и писать сырое целое.

## Цель

Гиперпрыжок включается, когда оба значения точные:

| Требование | Хранение | Ограничение в игре |
| :--- | :--- | :--- |
| Топливо = 1000.00 | int32, 16.16 | заправка останавливается на 50.00 |
| Тяга = 3.25 | int32, 16.16 | рычаг останавливается на 2.00 |

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab15_fixed_point
.\build\bin\Release\lab15_fixed_point.exe
```

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab15_build`, `lab15_solve_ok`, `lab15_wrong_fails`. Неверные ответы, которые обязаны
  провалиться: топливо записано как Float, сырое значение без масштаба 65536, тяга как Float, тяга округлена
  до целого, запись за границу.
* `solve/solve.py` — спойлер.

## Где пригодится на карте

Старые 2D/3D-движки и эмулируемые консоли, где позиции, скорости и шкалы хранятся в фиксированной точке.
