# Lab 16 — Array of Structs & Stride (Tier E- · 1.4)

**Предпосылки:** Lab 03 (структуры и двумерный массив в Hex View).
**Новая идея:** сущности игры лежат в массиве структур, и одно и то же поле следующего элемента находится
ровно на один размер структуры дальше (шаг, stride). Нашёл HP одного бойца — вычисли шаг и поправь весь отряд.

## Цель

Железный отряд выступает, когда у **всех 8** бойцов HP не меньше 500 и все живы. Лечение в игре упирается
в максимум HP бойца, а павшего из меню не поднять.

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab16_array_of_structs
.\build\bin\Release\lab16_array_of_structs.exe
```

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab16_build`, `lab16_solve_ok`, `lab16_wrong_fails`. Неверные ответы, которые обязаны
  провалиться: неверный шаг (одно поле забыто), только 7 бойцов из 8, павший остался павшим, правка максимума
  вместо HP, запись за конец массива.
* `solve/solve.py` — спойлер.

## Где пригодится на карте

Списки юнитов, врагов и предметов в стратегиях и экшенах: найди одну сущность — и пройди по массиву с шагом
структуры.
