# Lab 54 — Own Emulator: Guest RAM (Tier A · 6.5)

**Предпосылки:** Lab 18 (статический объект → указатель → данные). По плану ещё Lab 24 — не собрана.

## Цель

Попасть в таблицу рекордов консоли: жизней ровно 99, счёт ровно 50000. По мануалу консоли: жизни — гостевой адрес 0x0300 (1 байт), счёт — гостевой 0x0302 (2 байта, little-endian).

## Формат ввода

Только меню игры (номер действия). Режим Hardcore скрывает адреса.

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab54_emulator
.\build\bin\Release\lab54_emulator.exe
```

## Как проверяется

* Флаг печатает программа (в нём подмешан ответ); в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab54_build`, `lab54_solve_ok` (3 запуска), `lab54_wrong_fails` — эталонный ответ проходит, все неверные ответы из `solve/solve.py` (включая обходные) проваливаются.
* Подсказки — на карте (`docs/dojo-map.html`), `solve/solve.py` — спойлер.
