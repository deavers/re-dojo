# Lab 32 — Shadow VMT (Tier C- · 3.9)

**Предпосылки:** Lab 07 (vptr, таблица виртуальных методов, ReClass.NET).

## Цель

Подкупить Капитана (третий стражник): он должен соглашаться на взятку, оставаясь при этом Капитаном. Если подкупным
станет любой другой стражник, Маршал всё заметит.

Ввод — только меню игры (номер действия). Режим Apprentice показывает адреса объектов.

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab32_shadow_vmt
.\build\bin\Release\lab32_shadow_vmt.exe
```

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab32_build`, `lab32_solve_ok`, `lab32_wrong_fails` — эталонный ответ проходит, все неверные
  ответы из `solve/solve.py` (включая обходные) проваливаются.
* Подсказки — на карте, `solve/solve.py` — спойлер.
