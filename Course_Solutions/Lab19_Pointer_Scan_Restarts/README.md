# Lab 19 — Pointer Scan Across Restarts (Tier E+ · 2.1)

**Предпосылки:** Lab 18 (статический указатель, цепочка из трёх уровней).

## Цель

Найти путь от статического объекта мира к золоту героя, который работает **после перезапуска**, и ввести его.

Формат ввода: в меню пункт `5`, затем смещения через пробел от объекта мира, последнее смещение — до самого поля,
например `0x10 0x2C` (hex с `0x` или десятичные, до 8 смещений). Программа трижды заново собирает мир
со случайной раскладкой кучи и проверяет путь в каждом.

| Код выхода | Значение |
| :-: | :--- |
| 0 | путь принят, флаг напечатан |
| 1 | путь не дошёл до золота героя хотя бы в одном мире |
| 2 | испорченная строка пути |
| 3 | выход / конец ввода |

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab19_pointer_scan
.\build\bin\Release\lab19_pointer_scan.exe
```

## Как проверяется

* Флаг печатает программа (в нём подмешан введённый путь); в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab19_build`, `lab19_solve_ok` (3 запуска), `lab19_wrong_fails` — тесты управляют самим exe;
  все неверные пути из `solve/solve.py` проваливаются в каждом запуске.
* Подсказки — на карте, `solve/solve.py` — спойлер.
