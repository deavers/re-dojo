# Lab 45 — Mini-"UE": Name Pool (Tier B+ · 5.5)

**Предпосылки:** Lab 33 (RTTI) и Lab 35 (имена через хэши) — обе в плане, ещё не собраны.
**Новая идея:** движки вроде Unreal не хранят имена объектов строками внутри объектов: объект держит **индекс
FName** в глобальном пуле имён. Чтобы прочитать любое имя, нужно понять пул: где лежит глобальная переменная,
как хранятся чанки, как устроена запись и как индекс делится на чанк и смещение. Это первый шаг любого
SDK-дампера.

Свой мини-движок, не Unreal: пул из чанков по `0xC0` байт в куче (адреса меняются при каждом запуске), запись —
2-байтовый заголовок `длина << 6` + ASCII-символы с выравниванием до чётного смещения, индекс =
`(чанк << 16) | (смещение / 2)`. В бинаре имена зашифрованы XOR и расшифровываются в пул только при старте.

## Цель

1. **В игре:** три запечатанных объекта показывают только индексы FName — назови все три имени (флаг).
2. **Дампер:** напиши дампер всего пула и проверь его чекером.

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab45_name_pool lab45_name_pool_selftest
.\build\bin\Release\lab45_name_pool.exe
# проверка дампа: одна строка на запись, "<индекс hex> <имя>", порядок любой
Get-Content my_dump.txt | .\build\bin\Release\lab45_name_pool_selftest.exe
```

## Как проверяется (категория «чекер артефакта»)

* Чекер — это selftest-бинарь: он строит пул в своей памяти (со случайным размещением чанков) и сравнивает с ним
  дамп, полученный на stdin. Код 0 и флаг — дамп полный и точный; 1 — расхождение; 2 — испорченная строка.
* Эталонный дампер `solve/solve.py` от бинаря не зависит: расшифровывает таблицу из `lab45_core.hpp` и повторяет
  раскладку пула. Так проверяется, что лаба и эталон согласованы.
* Автопроверка (CTest): `lab45_build`, `lab45_solve_ok` (3 запуска), `lab45_wrong_fails`. Неверные дампы: нет
  последней записи, индекс = байтовое смещение (забыт шаг 2), сдвиг чанка 8 вместо 16, имя в другом регистре,
  испорченная строка (код 2). Настоящий exe проверяется на чистый выход при пустом вводе.
* `solve/solve.py` — спойлер.
