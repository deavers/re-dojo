# Lab 45 — Mini-"UE": Name Pool (Tier B+ · 5.6)

**Предпосылки:** Lab 17 (раскладка структур), CM 03 (XOR). По плану — Lab 33 и Lab 35, они ещё не собраны.

## Цель

1. **В игре:** три запечатанных объекта показывают только свои индексы имён. Назови все три имени (флаг).
2. **Дампер:** выгрузи из памяти игры **все** имена движка с их индексами и проверь дамп чекером (флаг).

## Формат ввода

* Игра: три имени через пробел, в показанном порядке.
* Чекер (`lab45_name_pool_selftest`): первая строка — `seed <N>`, где N — число, которое игра печатает при старте
  («Pool seed»); дальше по одной записи на строку: `<индекс в hex> <имя>`, например `0x00010004 Health`, порядок
  любой.

| Код выхода (чекер) | Значение |
| :-: | :--- |
| 0 | дамп полный и точный, флаг напечатан |
| 1 | дамп не совпадает с пулом этого seed |
| 2 | испорченная строка или нет строки `seed` |

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab45_name_pool lab45_name_pool_selftest
.\build\bin\Release\lab45_name_pool.exe
Get-Content my_dump.txt | .\build\bin\Release\lab45_name_pool_selftest.exe
```

## Как проверяется

* Флаг печатают игра и чекер (в нём подмешан seed); в репо — только sha256 флага чекера для эталонного seed.
* Автопроверка (CTest): `lab45_build`, `lab45_solve_ok`, `lab45_wrong_fails` — эталонный дампер (`solve/solve.py`,
  не зависит от бинаря) проходит чекер, все неверные дампы проваливаются. Игровой путь exe проверяется вручную.
* Подсказки — на карте, `solve/solve.py` — спойлер.
