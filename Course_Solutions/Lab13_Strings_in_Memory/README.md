# Lab 13 — Strings in Memory (Tier E-- · 0.8)

**Предпосылки:** Lab 12 (неточный скан, типы с плавающей точкой).
**Новая идея:** текст в памяти — не всегда ASCII. Поиск строки в UTF-16 (в Cheat Engine: тип String +
UTF-16) и правка строки с префиксом длины, где отдельный байт говорит, сколько букв читать.

## Цель

Зал легенд впускает, когда одновременно:

| Требование | Хранение | Ограничение в игре |
| :--- | :--- | :--- |
| Имя героя DRAGONSLAYER | UTF-16, буфер на 16 символов | меню переименования пускает не больше 8 букв |
| Тег гильдии DOJO | ASCII с байтом длины перед буквами | меню пускает не больше 3 букв |

## Сборка и запуск

```powershell
cmake --build build --config Release --target lab13_strings
.\build\bin\Release\lab13_strings.exe
```

## Как проверяется

* Флаг печатает программа; в репо — только его sha256 (`check/expected.json`).
* Автопроверка (CTest): `lab13_build`, `lab13_solve_ok`, `lab13_wrong_fails`. Неверные ответы, которые
  обязаны провалиться: имя записано как ASCII, длина тега не исправлена, тег записан поверх байта длины,
  неверный регистр, слишком длинное имя (выход за буфер отклоняется, а не роняет харнесс).
* В коде используется `char16_t`, а не `wchar_t`: `wchar_t` на Windows — 2 байта, на Linux — 4.
* `solve/solve.py` — спойлер.

## Где пригодится на карте

Имена персонажей, названия предметов и сохранённые строки в играх на Windows (часто UTF-16) и в
форматах сохранений с префиксом длины.
